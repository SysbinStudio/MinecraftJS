⛏️ MinecraftJS

用 JavaScript 复刻 Minecraft 1.20.1 —— 兼容原版协议，可直连原版服务器

MC 1.20.1 (protocol 763) Node.js ≥ 18 ESLint + esbuild 源码参考 mcsrc.dev

项目简介

MinecraftJS 是 Minecraft Java Edition 1.20.1 的 JavaScript 复刻实现。它逐模块翻译 net.minecraft.*（参考 mcsrc.dev 反混淆源码）的核心逻辑： Netty 帧协议、VarInt 编解码、NBT 序列化、区块与光照、实体物理、容器/合成、战斗与命令系统—— 并通过标准协议与加密握手直接加入原版服务器（离线模式或正版验证均可对接）。

核心特性

📡 原版网络协议

PacketEncoder / Uncompressed / Compressed 帧格式，zlib 压缩，VarInt21Frame 分帧，与 Netty 服务端字节级兼容。

🔐 AES 加密握手

Login Start → Server Hello → 共享密钥 AES-128-CFB8（CFB8-noPadding），复刻 EncryptionContextFactory。

🧱 NBT 全类型

NbtIo 读写、网络无名根复合体、SNBT 解析，支撑区块数据、物品组件与实体数据。

🌍 世界与区块

ChunkSection 调色板（direct / indirect）、方块状态、光照引擎（BlockLight / SkyLight）。

🚶 实体与物理

AABB 碰撞、重力、移动校正（attemptMove）、玩家输入同步与服务端权威位置。

🎒 背包与合成

Container 菜单协议（Serverbound/container clicks）、1.20.1 RecipeBook 配方匹配。

⚔️ 战斗系统

伤害管线（DamageSource）、攻击冷却、饥饿与再生，对齐 1.9+ 战斗机制。

💬 聊天与命令

1.19+ SignedMessageChain、命令树 Brigadier 解析与 Tab-Complete。

快速开始

# 安装依赖
npm install

# 连接一个原版服务器（示例）
node examples/connect-server.js play.example.com 25565 offlineSteve
const { MinecraftClient } = require('minecraftjs')

const client = new MinecraftClient({
  host: 'localhost', port: 25565,
  username: 'Steve',
  version: '1.20.1'          // protocol 763
})

client.on('login', () => console.log('已进入服务器:', client.serverMotd))
client.on('chat', (msg) => console.log(msg.unsignedContent))
client.on('kill', () => client.respawn())
client.connect()
